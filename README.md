# Frank Energie Dashboard

## Windows starten

Dubbelklik op `Start Dashboard.bat`. Het dashboard opent in je browser. Laat het
consolevenster open zolang je de app gebruikt; sluit het venster om de app te
stoppen.

De launcher gebruikt de bestaande `.venv`. Als die nog niet is aangemaakt, open
dan een terminal in deze map en voer uit:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```
